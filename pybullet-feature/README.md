# PyBullet


Этот репозиторий содержит набор тестов для симуляции манипулятора Aubo i7 в среде PyBullet.

## 1.Структура файлов

- Папка `aubo_i7` содержит файлы описания робота: 
    - `aubo_i7.urdf` - конфигурация с камерой и FT-сенсором. Применяется в тестах №1–4.
    - `aubo_i7_gripper.urdf` - конфигурация с гриппером и камерой. Применяется в тестах №5–6.
- Папка `figure` содержит файлы всех дополнительных мешей и моделей объектов, используемых в симуляциях.
- **Тест №1**:
    - `Test1_pos.py` - управление по декартовым координатам (MoveL)
    - `Test1_vel.py` - управление по скоростям (SpeedL)
- **Тест №2**:
    - `Test2.py` - cлежение за ArUco-маркером
- **Тест №3**:
    - `Test3.py` - измерение силы трения при контактном взаимодействии с объектом при фиксированной скорости
    - `Test3_1.py` - измерение силы трения при контактном взаимодействии с объектом при трех разных скоростях
    - `force_v_0.5.png`, `force_all_speeds.png` - графики усилия, полученные в результате теста
- **Тест №4**:
    - `Test4.py` - силовое взаимодействие с жёсткой стеной
- **Тест №5**:
    - `Test5.py` - захват объекта с нестандартной геометрией
- **Тест №6**:
    - `Test6.py` - захват упругодеформируемого объекта.
     *Примечание:* При проведении теста использовалась встроенная модель SoftBody из-за сложности с загрузкой модели с нестандартной геометрией. Также наблюдаются проблемы с захватом упругодеформируемого объекта, но при включении каркасного режима (клавиша W) видна деформация сетки объекта под действием схвата.

## 2. Как запустить

1. Установка зависимостей: Перед запуском необходимо установить библиотеки Python: `numpy`, `opencv-python`, `matplotlib`, `spatialmath-python`, `pybullet`.
2. Запуск: Открыть необходимый файл в удобном редакторе и запустить код.
